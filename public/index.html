Proxmox API키만 넣으면 전체 노드

클러스터면 노드 하나의 주소만 넣어도 됩니다. 에이전트가 API로 노드 목록을 받아 노드마다 서버로 등록하고, VM/LXC를 전부 가져옵니다. 클러스터에서 빠진 노드는 서버 목록에서도 빠집니다. 토큰 비밀은 server_secrets에만 저장됩니다.

에이전트는 깨울 서버마다 깔 필요 없습니다. Cloudflare Tunnel이 있는 항상 켜진 기기에만 두면 WOL, 공인 IP, 헬스 체크를 대신합니다.

서버 추가

Wake 방식과 Proxmox 연동은 서버마다 고릅니다.

Wake-on-LAN

에이전트가 집 LAN에서 매직 패킷을 3번 보냅니다. 유선 NIC MAC을 쓰세요. 서브넷이 다르면 브로드캐스트를 예: 192.168.219.255 로 지정하세요.

API 주소와 토큰만 있으면 에이전트가 노드 목록을 받은 뒤 VM/LXC를 전부 긁습니다. 노드를 적으면 그 노드만 봅니다. 비밀은 server_secrets에만 저장됩니다.

헬스 체크는 주소와 기대 상태 코드만 저장합니다. 인증 비밀은 환경 변수로 둡니다.
